01 / 产品流程

先看变化，再决定如何解释。

  1. 01

    原样保存版本

    通过文本框或 UTF-8 文件导入规则、知识文档。文件导入保留 CRLF、BOM 和空格；每个版本记录 SHA256，不允许覆盖。重复内容被拒绝，修改应成为新版本。

  2. 02

    定位差异

    逐行显示新增、删除、替换与未变内容，保留原文位置和比较快照。移动段落可能呈现为删除与新增；区块数量不是风险分数，也不等于业务事项数量。

  3. 03

    核对影响说明

    模型草稿必须引用对应版本的连续原文。格式或引用失败会保留诊断，使用者可手工补充、修订、确认或拒绝。修改后重新审核，版本冲突防止旧操作覆盖新判断。

  4. 04

    交付冻结简报

    只纳入已确认说明，并列出没有已确认说明的变更块。后续修订不改写历史简报。ZIP 包包含可离线阅读的 HTML、JSON、两份原文和哈希清单；清单用于完整性核对，不是数字签名。

02 / 验证记录

引用正确，也可能解释错误。

34 项自动测试

覆盖重复行、Emoji、换行、否定、重排及原文重建；版本与比较不可变、审核状态和冲突、简报快照不变、ZIP 哈希和 HTML 转义。文件导入验证 BOM/CRLF 保留、重复拒绝、无效编码和大小边界；访客演示另验证隔离、过期清理、请求额度和私人入口保护。

真实模型的两种失败

第一条合成探针重复输入字段直到输出截断，被拒绝保存。第二条文档包含诱导指令，模型生成“需要审批，但无需审批”的矛盾说明；引用校验通过，只保存为待审核草稿。这两条不是准确率评测，无法证明系统能识别全部语义错误。

浏览器完整流程

实操比较版本、手工说明、确认、冻结简报，再修订说明验证旧简报不变。另一次模型调用生成“新增审计记录”草稿。实际文件选择器导入后核对存储字节，CRLF 与原文件一致。390px 视口打开比较及历史简报，页面无横向溢出。

当前边界

已开放临时访客演示，尚无稳定云托管，没有真实客户使用成效。仅支持纯文本，不解析 PDF/Word；每版最多 20000 字符、500 行。浏览器下载落盘未验收，ZIP 内容通过实际 HTTP 下载和离线页面验证。

模型与交互迭代

格式通过，仍可能漏掉关键条件。

六条合成样例、两种提示方案共12次真实调用。基线4/6、候选5/6通过格式与逐字引用门槛；候选仍把文档指令解释为规则，遗漏期限或禁止例外，因此保留默认v1。这是由同一AI开发代理复核的开发对比，不是独立盲测或语义准确率。

手工说明增加“填入此块原文引用”，减少重新复制原文的操作。未保存说明时阻止切换变更块，避免误关联；引用未编辑时保留原始CRLF换行，修改后按实际输入校验。浏览器完成保存、修订、确认后，通过HTTP核对原始换行仍在。

03 / 工程取舍

保存证据，也保存未完成的判断。

研究了开源 Redlines 的文本差异形式，本版本没有复制或安装其代码，直接使用 Python 标准库 difflib。复用作品集已有模型适配和请求保护，SQLite 事务与版本号保障审核状态一致；模型不执行文档指令，不自动确认简报。
