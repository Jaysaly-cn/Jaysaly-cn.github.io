01 / 使用流程

从数据进入，到结果可复查。

  1. 01

    检查数据

    导入 UTF-8 CSV，保存原文哈希与列映射，查看类型、缺失数、唯一值与预览。前导零编码保留文本，空白按 NULL 处理。

  2. 02

    提出查询

    不熟悉 SQL 时，可选择分组、统计、单条件筛选与空值处理，确定性生成查询。也可以提问让模型提出候选。模型仅接收列结构、缺失计数、总行数和问题，不发送单元格内容。生成 SQL 提议并保留原文，生成不会自动执行。

  3. 03

    审核与执行

    核对聚合口径与排序，修改 SQL 后填写审核说明。只读查询在临时数据表执行，限制函数、耗时和返回规模；失败也有记录。

  4. 04

    查看与追溯

    查看表格及正负条形图，读取历史快照。可导出含 CSV、实际 SQL、原始 JSON 与说明的结果包，截断会明确标记；后续查询不会改写旧结果。

03 / 取舍与边界

先让查询过程可检查。

临时公网入口预置合成渠道数据，30分钟独立会话、每会话3次免费模型请求，可视化查询不依赖模型。数据临时保存在演示服务器，过期清理；仅使用合成资料。依赖开发机与临时隧道，非稳定云托管。公网两访客隔离、查询和导出已验证；真实模型仍出现将忽略空值写成补零的偏差，必须审核。

单 CSV 最多 2MB、10000 行和 40 列；查询最多返回 200 行并标注截断。图表直接绘制当前查询前 20 行，不二次聚合；选中数值列含 NULL 时提示先处理。小数采用浮点近似，不用于精确账务。

参考 PandasAI 的自然语言分析场景，未复制其实现。解析和受限 SQL 使用 Python 标准库，访问保护与模型接入复用作品集已有代码；保留来源说明。这里不运行模型生成的 Python，SQL 限制也不被描述成任意代码沙箱。
