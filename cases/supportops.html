直接体验完整处理流程。

每位访客独立空间，预置8篇合成知识。会话30分钟、最多60次写入、单次40KB；输入在演示服务器处理，请仅使用合成资料。免费小模型答复实测未达标，演示明确禁用生成，保留真实证据检索、人工工单和知识回流。

公网浏览器实测：离线激活问题最初只命中弱相关“恢复窗口”；记录问题、解决工单、审核发布知识后，新恢复步骤成为复查首条证据。旧回答和负面反馈保留，仍展示弱相关条目。390px视口完成复查判断，无整页横向溢出。由编程代理使用合成数据验收，不是客户评价。

01 / 业务闭环

知识命中以后，工作还没有结束。

v0.2 将已解决工单转为可审核的通用知识：编辑正文与适用范围、人工确认后发布，后续检索立即可见。工单版本、原回答、发布正文和审核说明分别留存；内部范围继承，旧回答不改写。v0.3 可用当前知识复查原问题，冻结前后证据及知识版本，再记录人工判断；不自动清除负面反馈，也不以命中数判定改善。

  1. 01

    导入资料

    导入 TXT、Markdown 或粘贴正文，设置来源与检索范围。提供 8 篇合成政策供首次体验。

  2. 02

    检索并核对

    执行 BM25Plus 检索，返回原文片段、来源和版本快照。关键词分数不被包装成模型置信度。

  3. 03

    反馈或转交人工

    记录有帮助或问题反馈；需要跟进时从回答直接创建工单，同一回答重复升级不会创建重复工单。

  4. 04

    处理与复盘

    认领、等待补充、解决、重新打开均保留事件记录。解决需要填写处理人和解决说明。

知识会更新，旧答复不应被改写。

资料可修订标题、正文、来源和范围，每次填写修改说明并生成新版本。过期版本请求会被拒绝；旧数据库只补记当前版本，明确更早历史不可恢复。删除资料不清除历史，重新载入示例也会延续版本号。

公网浏览器将合成退款申请期限从7天改为14天，资料历史保留v1/v2，旧问题复查同时显示原v1与当前v2证据。未保存编辑时阻止改选资料，390px视口可展开历史正文。范围变化只作用于之后检索，不改写旧回答或工单发布快照。

02 / 产品取舍

把能力边界做进流程。

证据与生成分开

没有模型凭据时展示真实检索摘录，不用模板输出冒充模型回答。模型连接失败时显示失败状态并保留证据。

执行由人确认

答复不会自动发送给客户，也不执行退款或修改账号。通过工单记录人工处理结果。

结果可以回查

删除知识资料不改写历史引用。回答、证据、耗时和处理轨迹可导出为 JSON。

后端保护业务状态

非法状态跳转与过期版本更新会被拒绝，避免仅靠前端按钮限制流程。

03 / 验证记录 · 2026-09-23

可复现的检查，明确的适用范围。

  • 30 项接口、模型协议、知识版本及访客隔离测试通过：持久化、状态约束、去重、范围过滤、认证、请求限制、模型失败等。
  • 20 条合成开发集用例通过：17 条有答案问题首位命中，3 条无证据或范围过滤场景符合预期。
  • 浏览器实测完成载入知识、退款查询、转工单、认领与解决；检查 1440px 桌面与 390px 手机布局。
  • 新增知识回流浏览器验证：编辑已解决工单、确认发布、再次提问首位命中新知识；旧回答保持不变。仍返回弱相关额外片段，不据此宣称语义准确率。
  • 浏览器复查合成旧问题：新增首条证据更有帮助，但仍存在弱相关片段；已保存判断和依据，原反馈保留。该判断由编程代理完成，不是客户评价。
  • 已真实测试免费 Qwen 0.5B / 1.5B。1.5B 的两条回答虽通过引用协议，却仍有无依据内容或未回答问题；因此不默认启用小模型客服生成。原始失败全部保留，协议成功率不是模型准确率。

04 / 运行与后续

从可用版本，继续迭代。

源码含环境锁定文件、测试、Dockerfile 和产品说明。按 README 启动后访问本机 8765 端口即可体验。GitHub Pages 展示本案例与源码；Python 动态服务已开放临时访客演示，依赖开发机与隧道在线，尚无稳定云托管。

本版本为单团队工作台，内部/对客属于检索范围，不是角色权限隔离。后续优先补工单分类编辑、真实试用反馈、更强免费模型和独立事实支持评测；竞品研究与营销内容工具已分别开发。
