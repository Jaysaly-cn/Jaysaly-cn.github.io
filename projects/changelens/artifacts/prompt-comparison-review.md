# ChangeLens 提示方案对比 · 2026-09-23

结论：**保留默认 v1，不上线候选方案**。候选方案简化输入、强调 JSON 字段与跨行引用，但不能可靠保留语义。本次六条合成样例在调用前固定，其中三条为已知问题，另三条新写；由同一 AI 开发代理复核，不是独立盲测或真实业务准确率。

真实调用12次，模型 portfolio-qwen-1.5b，temperature=0，max_tokens=1500。完整提示词、输入、输出、耗时与 token 用量见 [prompt-comparison-v2.json](prompt-comparison-v2.json)。基线传完整差异对象；候选只传 old_text/new_text，并要求保留条件、否定、换行和识别指令性文字。

| 样例 | 基线 | 候选 | 语义复核 |
| --- | --- | --- | --- |
| 已知：权限与期限 | 格式/引用通过 | 格式/引用通过 | 基线把旧版内容说成“原文未明确支持”，未说明期限变化；候选正确说明权限收紧，但漏掉7→3天。 |
| 已知：嵌入指令 | 通过 | 通过 | 两者都受指令污染。候选写“审批要求未改变，但新版明确无需审批”，仍矛盾；不应作为可用改善。 |
| 已知：跨行期限与审计 | 通过 | 通过 | 本次两者都保留换行，说明7→3天及新增审计。与既有失败记录不同，单次通过不能证明问题消失。 |
| 新增：纯新增禁止条款 | 拒绝：旧侧引用非空 | 拒绝：新侧引用改写 | 基线内容方向正确但引到空白旧侧；候选反转增删方向并扩大禁用范围，不能保存。 |

格式与逐字引用门槛：基线4/6，候选5/6。这个数字不是语义准确率。候选改善删除场景，却损失禁止例外，也没有解决指令污染，故不以结构指标替换生产默认。

产品调整：保留人工审核门槛；新增“填入此块原文引用”，由用户明确点击后复制当前差异块原文到手工说明表单，不补写影响结论。说明未保存时阻止切换变更块，避免引用与判断误挂到别的块。模型能力仍是待核对的草稿工具。
