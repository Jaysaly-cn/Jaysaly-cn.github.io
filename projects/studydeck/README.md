# StudyDeck

资料驱动的学习卡片工作台：保存原文 → AI 或手工制作草稿 → 人工校对 → FSRS 到期复习 → 导出记录。

这是作品集中的学习场景实验，动态工作台提供临时公网演示，源码和案例已加入公开陈列馆；没有真实学习效果数据。

## 启动

Python 3.12，安装 `requirements.txt` 后：

```powershell
$env:SD_MODEL_BASE_URL='http://127.0.0.1:8771/v1'
$env:SD_MODEL='portfolio-qwen-1.5b'
python -m uvicorn app.main:app --host 127.0.0.1 --port 8794
```

打开 http://127.0.0.1:8794 。模型可选，未配置时手工制卡、确认和复习仍可使用。当前适配器只接受本地模型，不产生付费 API 调用。模型会接收选中的完整资料（最多 12000 字符）；上下文过长可能生成失败。

## 工程实现

- FastAPI + SQLite，资料、卡片、事件持久化；默认数据库 `data/study.sqlite3`，可通过 STUDYDECK_DB 覆盖。
- 直接使用 [py-fsrs](https://github.com/open-spaced-repetition/py-fsrs) 6.3.2（MIT），不自行重写调度算法。关闭随机扰动；默认目标保留率是调度参数，不是效果承诺。
- 引用必须逐字存在于原文。此检查不能判断答案的语义正确性，确认时仍需人工核对。
- 批量生成全成功才保存，任何引用无效都会回滚；草稿无法评分。
- 确认和评分在 SQLite 写事务内检查版本；重复评分和提前评分返回 409。
- 每次评分保留卡片快照、FSRS review log 和 scheduler 参数；JSON 导出包括全部资料和事件，不重新计算。
- 默认只允许本地 API 请求并拒绝跨源请求。暂不提供公网部署或多用户登录；环境令牌仅适用于 API 客户端，网页尚无令牌输入界面。

## 修订已确认内容

卡片库中的“修订内容”支持已启用或暂停卡片。修改并填写原因后回到待确认，清除当前调度状态；旧内容、评分和调度快照保留在事件中。重新确认后作为新学习内容安排复习。内容未变、引用无效或版本过期时不修改数据。新增 3 项测试，合计 15 项通过；浏览器实际修订合成卡片，状态回到待确认，并通过导出核对旧评分留存（artifacts/revision-browser.json）。

## 访客隔离演示服务（部署准备）

运行 `python -m uvicorn app.demo:app --host 127.0.0.1 --port 8795` 可启动独立演示服务。每个 cookie 会话使用单独数据库，30 分钟到期；最多 12 个会话、每小时 30 个新会话，每会话 60 次写操作、3 次模型请求，模型全局每小时 24 次；输入上限 40KB。模型失败也消耗请求额度。公网反向代理需设置精确 SD_DEMO_HOST，当前演示地址见下文。必须单进程运行，会话状态不跨 worker 共享。

复用 DataBrief / EvidenceBrief 的隔离网关实现，演示不访问私有工作台数据库。测试覆盖跨会话卡片、资料写入和导出隔离、过期清理、主机/来源校验、输入大小、会话容量和模型限额；合计 21 项测试通过。Windows 测试发现初始化连接未关闭导致清理失败，已用显式关闭修复。浏览器已看到独立合成资料和演示说明，公网端到端验收见下文。

## 生成记录

新增生成记录页，可查看模型请求失败类型、格式错误字段、具体引用不匹配的卡片序号，并对照原文和原始输出手工制卡。失败批次不创建卡片或卡片事件，诊断记录单独保留；成功仅代表草稿入库，不代表语义正确。每个工作台最多100条记录，达到上限仍可手工制卡；升级前请求不补录，服务中断请求可能无记录。JSON 导出新增 generations 字段。

26项测试通过，包含真实失败输出回放、格式错误、异常信息脱敏、重开数据库与容量上限。新的本地模型请求引用精确但误定义幂等，原始证据见 artifacts/generation-history-live.json，卡片未审核。浏览器验证记录页可展开原文及原始输出。临时公网后端已升级，诊断记录同样按访客隔离，相关跨会话测试已通过。
