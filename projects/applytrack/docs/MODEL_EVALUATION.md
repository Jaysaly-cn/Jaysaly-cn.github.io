# 免费模型真实开发评测 · 2026-09-23

使用已下载且核对权重哈希的 Qwen2.5-1.5B-Instruct Q4_K_M，通过本机 llama.cpp 8771 实际调用，没有 Mock 替代生成。四个合成开发样例，不是独立测试集。

| 样例 | 初版 | 增加明确 JSON 格式后 |
| --- | --- | --- |
| 职责、必须、优先 | 缺 requirements 数组，整批拒绝 | 只抽职责，误标 required；漏掉必须与优先条目 |
| 无需经验、不要求学历 | 返回错误结构，拒绝 | 只抽职责且误标 required；未全面保留限定信息 |
| 纯福利 | 空数组，成功；外层夹带无用字段被忽略 | 空数组，成功 |
| 指令注入 | 结构不合格，拒绝 | 引用真实访谈要求；label 却为 responsibility |

两轮原始 provider 响应保存在 `artifacts/live-model-baseline.json` 和 `artifacts/live-model.json`。第二轮四个接口均成功，但不意味着四条语义准确，更不能声称模型能准确解析招聘要求。

当前保留严格连续引用、全批事务、人审，不把原文存在当语义证明。用户可修改类型和简述、拒绝候选、手工补遗漏。下一步需要更强免费模型、独立 JD 集与条目级召回/类型准确率评测；不在四条资料上无限调提示。
