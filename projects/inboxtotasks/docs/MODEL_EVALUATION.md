# 免费模型开发验收 · 2026-09-23

本机Qwen2.5-1.5B-Instruct Q4_K_M，CPU llama.cpp服务8771。四条合成开发样例，不是独立盲测；不统计或宣传总体准确率。

|场景|HTTP|人工核对|
|---|---|---|
|明确负责人和日期|201|提取提交方案，负责人和日期短语来自引用；仍为draft|
|不用更新、已经完成|201|空结果，符合此样例预期|
|任务改期、原安排取消|201|空结果，漏提当前改期任务|
|引用旧邮件、无新任务|201|空结果，符合此样例预期|

约0.7–4.2秒，仅代表本机短文本。重放命令：`python -m evals.live_model`，会消耗本地推理、保存合成邮件和模型运行记录。原始输出与响应保存在artifacts/live-model.json。协议通过不代表召回完整；不针对这四条样例反复调提示后冒充独立评测。

工程限制：输入4000字符上限，单进程推理锁，30次/封；超过上限提示手工补充，未实现长邮件分段。模型只能提议title/quote/owner/due_phrase，不推算绝对日期、不批准、不操作外部系统。所有引用和提议字段字面校验通过后才整批落库，失败保留raw但不生成任务。
