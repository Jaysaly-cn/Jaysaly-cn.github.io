# ContentBench · 营销内容工作台

真实 FastAPI + SQLite 应用：品牌事实 → 免费模型起草 / 手工录稿 → 规则检查 → 修订版本 → 人工审核 → 冻结导出。没有自动发送社交媒体内容。独立主源码在本机 contentbench 仓库维护，当前 GitHub 路径是个人主页仓库内的源码镜像。

## 启动

Python 3.12：

```sh
python -m venv .venv
# 激活虚拟环境后
pip install -r requirements-lock.txt
python -m uvicorn app.main:app --host 127.0.0.1 --port 8767
```

打开 http://127.0.0.1:8767 。无模型时仍可录入、检查、修订、审核和导出；界面明确显示模型未配置，不用模板伪装成模型生成。

本机免费模型实际验证：Qwen2.5-0.5B-Instruct Q4_K_M + llama.cpp b11118 CPU。Windows PowerShell 在启动应用前设置：

```powershell
$env:CB_MODEL_BASE_URL='http://127.0.0.1:8770/v1'
$env:CB_MODEL='portfolio-qwen'
python -m uvicorn app.main:app --host 127.0.0.1 --port 8767
```

模型部署及哈希见 [本机模型说明](docs/LOCAL_MODEL.md)。也允许 `https://openrouter.ai/api/v1` + 明确以 `:free` 结尾的模型 + `CB_MODEL_API_KEY`；未验证该在线路径，不保证额度。其他远程提供方及收费型号拒绝调用。

## 完整使用路径

1. 点击“填入合成示例”，检查品牌事实、出处、禁用词及必带说明后保存活动。
2. 选择渠道，点击“用免费模型起草”，或手工录入稿件并勾选关联事实。
3. 查看规则问题。模型新稿、人工新稿与修订版均为待审核。
4. 创建修订版，补齐说明、纠正事实和措辞。旧版本内容保留，新版本重新审核。
5. 核对事实原意、出处与适用条件，填写审核说明并批准；有规则阻断项时不能批准。
6. “冻结已批准稿件”只收录每份稿件当前已批准的版本，下载带 brief、事实、版本、审核说明的 JSON 或可读 Markdown 交付包。之后改稿不会改变旧快照。

## 范围与限制

单团队本地工作台，无多租户、账号角色或可验证的审核人身份。brief 创建后固定（更新事实需新活动）；每活动最多 50 稿件，每稿最多 30 版本。渠道字数是工作台约定，非实时平台规范。数字检查只看关联事实中是否出现相同数字；不能验证单位、语义、条件或市场宣传适用性。禁用词为字面匹配，不能覆盖所有同义词和规避表达。关联 fact_ids 不等于逐句自动溯源。

JSON / Markdown 导出是冻结交付包，未接入 CMS、社交账号或自动投放。已提供访客隔离临时演示；GitHub Pages 呈现案例与源码，动态服务依赖开发机在线。没有真实用户增长/提效数据。代码由 AI 编程协作实现，作品集应结合自己的理解与复盘展示。

数据库与日志默认保存在 `data/`，不提交源码。远程部署必须设置 `CONTENTBENCH_ACCESS_TOKEN` 并配置 HTTPS 反向代理；令牌是团队共享访问控制，不是身份系统。未配置令牌时 API 只接受本机地址与本机 Host；请求流体积限制 400KB，每分钟最多 60 次写请求。模型只接受服务器端环境配置。

## 可读交付包

每条冻结记录可下载 JSON 或 Markdown。两种格式来自同一份已保存快照，Markdown 包含活动要求、各稿件的渠道/版本/标题/正文/关联事实/审核说明，以及完整品牌事实出处。所有输入内容按字面代码块展示，不把输入 HTML 或链接当成可执行内容；没有自动投放。

[交付验证记录](docs/DELIVERY.md) · [真实合成活动的冻结包](artifacts/delivery-snapshot.md)。

## 提示对比与缺说明修订

两模型、两提示、六条合成案例的24次真实调用已完成；候选提示未达到替换标准，当前模型与提示不变。[完整结果与限制](docs/PROMPT_COMPARISON.md)。界面提供“补入必带说明后编辑”，把活动说明填入尚未保存的修订版；保存后仍需核对语义并重新审核，不会自动批准。
