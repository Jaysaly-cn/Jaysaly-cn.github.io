# Markdown 冻结交付 · 2026-09-23

此前只有 JSON 快照。本轮新增同一快照的可读 Markdown，便于人工交付、阅读与复核品牌出处。路由 GET /api/exports/{id}?format=markdown；默认仍为 JSON，其他格式422，缺失快照404。响应为 text/markdown 附件与 nosniff，不新增任何外部发布操作。

用户输入保留在字面代码块；围栏长度超过输入中最长连续反引号，HTML、Markdown 链接和嵌套围栏不会逃逸为普通文档节点。静态标题与事实 ID 来自固定模板或既有严格输入规则。每份稿件包含渠道、稿件/版本 ID、版本号、来源、模型标识、标题、正文、关联事实和审核说明，附完整 brief 和事实出处。

新增3项测试，全部23项通过：冻结后修改最新稿件，旧 Markdown 字节不变、JSON 保持一致；未批准稿件不进入包；特殊内容保真；格式与记录边界。最初攻击样例里的 alert(1) 被已有数字检查阻断，改成不含数字的 alert() 后验证围栏，无放宽业务规则。10条词法规则样例通过，JS语法通过。

实时本地 HTTP 从既有合成活动的已批准 v2 快照生成1479字节 Markdown，原文标题/正文/审核说明逐字匹配，见 ../artifacts/delivery-http.json 与 delivery-snapshot.md。没有重新跑模型或声称质量提升。浏览器打开旧活动，看见 JSON/Markdown 两种按钮；点击后显示已请求下载。文件内容通过 HTTP 独立核验，不宣称浏览器文件保存位置或外部编辑器互通已验收。

关联事实不是逐句自动溯源；冻结只证明所交付版本稳定，不能证明营销语义与宣传条件正确。未新增账号身份、CMS 或社交媒体发布能力。
