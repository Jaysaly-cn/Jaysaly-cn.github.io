# 访客隔离公开演示 · 2026-09-23

临时入口：https://surrounded-symphony-summit-flags.trycloudflare.com

这不是稳定云托管。开发机、模型进程或隧道退出后入口不可用；重启会失去会话。请仅输入合成资料。与私有工作台使用不同目录和数据库，不复制私有会议。

## 部署

```powershell
$env:MA_DEMO_HOST='你的确切演示域名'
$env:MA_MODEL_BASE_URL='http://127.0.0.1:8771/v1'
$env:MA_MODEL='portfolio-qwen-1.5b'
python -m uvicorn app.demo:app --host 127.0.0.1 --port 8805 --workers 1
```

HTTPS 反向代理连接本机 8805。必须单进程；会话、限流与清理状态在内存中。不要把私有 `app.main:app` 直接替换成免鉴权公开服务。

## 边界

- 每个随机 HttpOnly / SameSite=Strict Cookie 对应一份 SQLite；HTTPS Cookie 使用 Secure。30 分钟到期，最多12个并发访客空间，每小时最多30个新空间。
- 每位访客最多60次写请求、3次真实模型尝试；失败计次，成功段复用不计次。全局模型每小时24次，工作台写入守卫仍有每分钟60次限制。重启清空内存额度，不适合对抗持续滥用。
- 输入最多40KB，核心业务的会议/行动数限制保留。模型额度耗尽后可手工补充、确认、跟进、导出。
- Host 必须精确匹配配置；校验 Origin，拒绝跨站写入。客户端伪造隔离头无效；只有演示中间件可设置服务器请求 scope 标记。
- 清理仅针对专用目录的匹配文件；活动请求结束前不删除数据库。后台每20秒回收过期空间，旧进程残留文件超过35分钟可回收。退出时清理非活动空间。
- 无账号、团队身份、持久化工作区、分布式限流或日历同步。导出是文件快照，分享 Cookie 仍等同分享空间。

## 验证

30项自动测试通过，其中5项新增测试覆盖双访客会议/任务/导出隔离、模型额度与失败计次、成功复用、过期活动请求、席位上限、Host/Origin/体积限制、私有接口伪造头、全局24次限流。

真实公网 HTTP 使用免费本机 Qwen2.5 1.5B：49字符合成会议，约4000ms返回两条候选。重复提取复用原运行，运行数仍为1。人工确认明确承诺后 JSON/CSV/ICS 都返回200，另一访客导出为空，跨访客会议读取和任务写入均404。记录见 [public-smoke.json](../artifacts/public-smoke.json)，可用 `python -m evals.public_smoke <已配置的演示URL>` 重现。

这只是单条开发样例，不是模型准确率评估。既有否定误提取与长段超时记录仍适用。浏览器另行验证真实提取、人工确认和看板流程；导出内容以 HTTP 核验为准，不宣称日历客户端互通。
