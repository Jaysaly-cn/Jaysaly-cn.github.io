# MeetingActions · 会后行动台

把会议文字记录变成可追踪的行动承诺。真实 FastAPI / SQLite 后端、免费本机模型提取、原文定位、负责人/期限确认、跨会议任务看板、受阻/完成/重新打开、改期审计和 JSON / CSV / ICS 导出。

不是录音工具，也不会自动给参会者发送消息。模型候选不自动成为任务。

## 启动

Python 3.12：

```sh
python -m venv .venv
# 激活虚拟环境后
pip install -r requirements-lock.txt
python -m uvicorn app.main:app --host 127.0.0.1 --port 8768
```

浏览器打开 http://127.0.0.1:8768 。未配置模型仍可导入文字、关联原文、确认和跟进任务；没有模板冒充 AI 提取。

免费本机模型示例（先按 [本机模型说明](docs/LOCAL_MODEL.md) 启动 llama.cpp）：

```powershell
$env:MA_MODEL_BASE_URL='http://127.0.0.1:8771/v1'
$env:MA_MODEL='portfolio-qwen-1.5b'
python -m uvicorn app.main:app --host 127.0.0.1 --port 8768
```

也允许确切端点 `https://openrouter.ai/api/v1`、`:free` 型号与 `MA_MODEL_API_KEY`；本项目未实测在线免费额度。其余远程端点或收费型号在请求前拒绝。

## 使用

1. 创建会议，填写日期、参会者和带发言人的原文，可读入 TXT / Markdown。原文保存为不可变快照和 SHA256。
2. 选择原文分段，让模型提取或手工补充候选。引用必须逐字存在；负责人必须在参会者中，并在引用或紧邻的明确发言人前缀中出现。多处相同片段须消歧。
3. 核对“这是明确行动承诺吗”。编辑任务内容、选择负责人、确认日期，或明确选择未约定期限，填写说明；可退回误提取内容。
4. 从跨会议看板进入进行中、受阻、已完成等状态；完成需填写成果说明，重开有记录。调整负责人或期限保留之前值。
5. 按负责人或逾期筛选；下载全部已确认任务。CSV 转义公式开头，ICS 仅输出有期限的未完成任务，日期型全天事件，不包含邀请或收件人。

## 范围与限制

- 首版只处理文字，无录音、ASR、说话人识别、邮件/日历同步、外部任务系统或自主追催。可以使用其他转写工具产生的文字，但本项目未集成其 API。
- 完整记录最多 80000 字符，按最多 4000 字符逐段提取；界面与轨迹显示范围、已完成与失败段。成功段默认复用，勾选重新调用才再次运行。没有自动队列，跨段语义仍需核对；详见[分段实测与限制](docs/SEGMENT_EVALUATION.md)。
- 明确支持 ISO 日期、今天/明天/后天、本周/下周 + 星期；“尽快”“周五”等模糊词不猜日期。本周已过去的日期仍按字面计算，由人确认。日期基于填写的会议日期；逾期按服务器本地日期计算，不支持时分和跨时区截止时间。
- 引用存在及发言人前缀匹配不能证明指派语义，模型会误提取否定或讨论事项。必须人工确认；开发样例不能替代盲审或真实用户验收。
- ICS 是一次性截止日期快照，不是日历同步。重新下载不保证客户端删除已完成/取消的旧事件；未进行 Outlook / Apple Calendar 导入互通验收。JSON/CSV 含所有已确认状态，ICS 排除已完成、取消及无日期任务。
- 单团队共享令牌，无个人身份、多角色、多租户。远程部署需 `MEETINGACTIONS_ACCESS_TOKEN` 与 HTTPS 代理；无令牌时仅本机 Host / 地址可读写 API。400KB 请求限制、每分钟60次写请求、单进程模型串行。部署多 worker 前需要统一限流。
- 每工作台最多100场会议，每会议100项行动。模型运行轨迹未做长期归档策略。数据库在 data/，不进入源码。公网动态服务和独立远程仓库仍待部署条件；当前 GitHub 发布为个人主页仓库源码镜像。

代码经 AI 编程协作完成。合成会议不是真实业务案例，没有客户节省工时或模型准确率承诺。
