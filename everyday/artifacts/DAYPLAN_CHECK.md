# 周末半径开发与公开验证

2026-09-24。第六款工具已公开。以下测试为桌面 Chromium；地点与偏好使用自建虚构数据，不是实际商家推荐。

## 模型与规划

复用 Pantry 的固定版本 multilingual MiniLM q8，文件与 SHA-256 见 `../data/semantic-model.json`。模型及词表约 135.4 MB，另需引擎。真实向量余弦相关度匹配偏好；128 token 上限明确拒绝，不静默截断。

在最多 8 个候选、4 站的范围内搜索时间窗、转场、预算与必去项都成立的排列，以非负语义分数之和选择，同分优先早结束与低花费。不是地图最短路线或真实用户偏好概率。首站假设开始时已可到达，站间转场为用户填写的统一预留。

## 实际浏览器验证

| 输入 / 操作 | 观察结果 |

实际浏览器下载 TXT、三事件 ICS，以及带虚构标记的单事件 ICS。使用独立 Python `icalendar 7.3.0` 解析：事件数、开始结束时间与页面一致；UID 唯一、CRLF、UTF-8 每行不超过 75 字节。ICS 为本地浮动时间，不含时区和自动提醒；导入日历时需核对本地时间。未在实际第三方日历客户端导入测试。

## 自动测试与边界

目录共 36 项自动测试，DayPlan 新增 7 项：无效日期/跨日/重复地点/不安全链接、贪心策略错失的可行排列、必去与预算优先、等待及手动冲突、8 选 4 的 2081 状态边界、ICS 文字转义与换行折叠、缺失模型分数与过量必去项。

名称、营业时间、价格、来源均由用户填写；模型不会查询或补造，页面不读取来源链接。示例虚构标记随结果与导出保留。地点与偏好不上传，刷新后清空。未验证模型服务全球可达、实体低内存手机、实际八分钟超时或真实用户推荐满意度。工具有取消和失败重试，不承诺首次离线运行。

## 公网验收

公开地址 https://jaysaly-cn.github.io/everyday/dayplan.html ，代码提交 `be28ba8f004c51b4c55ca63e3b06b8f5984799aa`。Pages 与 Everyday AI 工作流成功，36 项自动测试通过；六项公开入口、页面、脚本和模型配置与 Git 版本逐字节一致。

没有使用内置样例按钮：手动添加“自建测试·阅览室”和“自建测试·篮球场”，描述显式标为虚构，偏好为“想安静地读书学习，暂时不做剧烈运动”，最多一站。实际模型推理 1.9 秒含准备，选中阅览室 15:00–16:00，等待 60 分钟。浏览器已有同模型缓存，不能当作新设备冷启动速度。

实际下载 TXT 和 ICS，独立解析器再次核对单事件标题、15:00–16:00 时间与描述。随后手动移除阅览室，空安排禁用导出；从折叠备选中加入篮球场后重新安排为 14:00–15:00，导出恢复可用。没有替用户向日历服务写入事件。
